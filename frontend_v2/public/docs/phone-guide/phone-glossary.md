# Phone glossary

The meaning of every mark and term on the phone screens. The same sentences appear beside each mark in Loupe.

## Record

One item read from a phone report, such as a message, a call or a contact.

## Reading

How Loupe interprets a record, for example which field is the sender.

## Mapped by the system, not yet confirmed

Loupe applied a reading to this value and no person has checked it yet. Open it to see the rule in plain words, and confirm or correct it.

## Machine-generated

A model produced this text, such as a transcript. The source stays shown above it. It is not confirmed until a person checks it.

## Confirmed

A named person checked this reading and confirmed it on the date shown.

## Read by a model, accepted

A model read this value and a named person accepted it on the date shown.

## Corrected

A person corrected this value. The original stays shown beside it. Only the corrected value is searched, counted and exported.

## Deleted

The phone marked this record as deleted. It was deleted at some time before the extraction; the report does not say when.

## In trash

The phone held this record in a trash or recently deleted folder at extraction.

## Recovered by carving

Recovered from raw storage rather than from an app's own records, so its time and sender may be missing.

## Synced from another device

The record came to this phone from another device on the same account. It does not show this phone was used at that time.

## Found more than once

The same record appears more than once in the report. Each copy stays listed; a person can mark one as not a copy.

## Also on another phone

The same message appears on another phone in this case. Both copies are kept.

## Decoding confidence

How sure the extraction tool was when it decoded this record. Low means check it against the source.

## Empty placeholder

The report lists a file here but the file has no content. It is not missing and not altered.

## Generic reading

No reviewed rule covers this record type yet, so Loupe shows its fields as they are, without naming sender or recipient.

## Uncertainty radius

The circle around a location point where the phone may have been. A point with no radius is drawn dashed as Accuracy not recorded.

## No data

The phone holds no records for this period. That is not the same as no activity: the phone may have been off, wiped or not recording.

## Phone summary

The first page for each phone: what was read, the period covered, what is missing and what needs a decision.

## Needs a decision

Settings and readings that a person must confirm or set, such as the owner and the time zone.

## Add to…

Puts phone records into a dossier, finding, theory, note, the Timeline or a label, keeping a link back to each record.

## Lead for enquiry

A result that points to something worth checking. It is not a conclusion for a report until a person checks it.
