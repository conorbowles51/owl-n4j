# Loupe export fonts

These SIL Open Font License fonts ship with the application so generated documents do not fetch fonts from a network.

- Space Grotesk variable: `https://github.com/google/fonts/blob/main/ofl/spacegrotesk/SpaceGrotesk%5Bwght%5D.ttf`
- IBM Plex Sans variable: `https://github.com/google/fonts/blob/main/ofl/ibmplexsans/IBMPlexSans%5Bwdth%2Cwght%5D.ttf`
- IBM Plex Mono regular: `https://github.com/google/fonts/blob/main/ofl/ibmplexmono/IBMPlexMono-Regular.ttf`

Downloaded 11 November 2026. Each family has its OFL license beside it. PDF/HTML embed the font files as data resources. Word embeds obfuscated copies under the Open XML font embedding specification. The export logo is copied from the repository's Loupe brand kit; it is not newly generated artwork.
