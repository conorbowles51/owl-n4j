# RSMF 2.0.0 manifest schema

`rsmf_schema_2_0_0.json` is Relativity's published manifest schema, copied unchanged from
https://github.com/relativitydev/rsmf-validator-samples (`RSMFManifestSchema/rsmf_schema_2_0_0.json`, commit
c717cd322264b46115d27d034a6107c8c91043d8), under the licence in `LICENSE` (kCura LLC, BSD-style). Loupe's RSMF export
(`../rsmf.py`) validates every manifest it writes against it before the file is delivered.
