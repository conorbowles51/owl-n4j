# Timeline guide

The Timeline puts the case's dated material in one order: events found in processed files, payments added from the ledger, findings and observations given a date, and photos with a date taken. Use it to see what happened before and after a moment, to check a sequence someone has described, and to pick out a period for a theory.

## Main controls

***Along the top.*** Filters opens the list of event types and names. The search box finds events by their words; press / to jump to it. The date buttons narrow the dates. The count on the right says how many events are shown out of all of them, for example "120 of 4,310 events". Export saves what is shown.

***On a case with phones.*** A Phones button, with the number of phones, opens the phone entries under the events. Two more controls can appear above the toolbar: Open the window around this, and What the phones did once a date range is set.

***The events.*** Events run in date order under a heading for each day, with the number of events on that day. Click an event to open its source. Ctrl-click, or Cmd-click on a Mac, picks several events at once for a theory or an export.

## Reading an event

***What each event shows.*** Its time, its type, its name, any amount (with money in and money out marked), a short summary, and the people, companies, accounts and places linked to it. When the search box holds words, they are highlighted in the event.

***When the time is missing.*** An event with a date and no time shows "No time" instead of a time. A time with no known time zone is shown as entered, never moved to another zone. Its place in the day is not a claim about the hour.

***Where it comes from.*** A line under the event says what it was built from: "Open payment and statement" for a payment, the file name for a photo, or the finding or observation it came from. "Saved copy; source changed or removed" means the source changed after the event was added; the event keeps the copy made at the time.

***Events written by the model.*** "Model reading, not checked" followed by a file name means the model wrote the event from that file. No person has checked it, and it is not a row of the ledger. Open the file before relying on the date or the amount.

***Amount unknown.*** "Amount unknown · check source" means the amount could not be read. Open the source to find it.

## Choosing the dates

***What it does.*** All shows every date. 30D, 90D and 1YR show the last 30 days, 90 days or year counted back from today, not from the case's own dates. Custom shows two date boxes for a from and a to date.

***When to use it.*** Use Custom for the period under examination. On an older case, 30D, 90D and 1YR can show nothing, because they count back from today.

***How to read the result.*** The count on the right changes to show how many events fall in the dates. A set date range also opens What the phones did on a case with phones.

## Filtering by type and name

***What it does.*** Filters opens a side list. Event Types lists every kind of event with a tick box, with All and None to tick or clear them all at once; above eight types a box finds a type by name. Entities lists the people, companies, accounts and places linked to events, grouped by kind, each with the number of events it appears in. Tick a name to show only events linked to it, or press Focus to show that name alone.

***When to use it.*** Use it to follow one person or account through time, or to take payments out and read only the messages and meetings.

***How to read the result.*** The Filters button shows how many filters are on. Clear all filters puts everything back. When nothing matches, the screen says "No events match your filters" with a Clear filters button. On a narrow screen the list opens over the Timeline and closes when you press Focus.

## Events with no time recorded

***What it does.*** Events whose date cannot be used are listed apart at the foot of the screen, under "No time recorded", with their count. Each shows its type and the date as entered, or "no date entered".

***When to use it.*** Open this list before treating the Timeline as complete. These events are kept and counted, never dropped, and never placed at a guessed time.

***How to read the result.*** The name, the type and the date as entered are there to find the item at its source and check its date.

## Opening the source of an event

***What it does.*** Clicking an event opens where it came from. A payment opens its ledger row with its statement. A finding or observation opens in the case's casework panel. A money trail opens its review. A photo opens the file in the document reader in a new tab. Any other event opens the details of the item in the side panel.

***When to use it.*** Open the source before quoting an event, and whenever a date or amount matters.

***Arriving from Financial.*** After Add to Timeline on the Financial screen, the Timeline opens with the new event chosen and a Back to Financial button. If the event is not in the current view, the screen says so.

## Keys on the Timeline

| Key | What it does |
|---|---|
| Down arrow or j | Move to the next event |
| Up arrow or k | Move to the previous event |
| Enter or Space | Open the event in focus |
| Escape | Clear the chosen event |
| Alt with Left or Right arrow | Jump to the previous or next group of events, where a gap separates one burst of activity from the next |
| [ or ] | Show or hide Filters |
| / | Go to the search box |

The keys do nothing while a dialog is open.

## Photos on the Timeline

***What it does.*** Every photo whose own data holds a date taken appears on the Timeline as "Photo taken", with a small picture of the photo. Its summary gives the file name, any caption, the place in the photo's data and the camera. Its source line reads "From the photo's data, not checked by a person.", then the photo's time zone ("UTC offset +01:00", or "Time zone not recorded.") and "A camera's clock can be wrong."

***When to use it.*** Use it to place photos beside messages, payments and phone activity on the same day. Photos with no date taken are not shown here until a person gives them a date.

***How to read the result.*** A photo's date comes from the camera or phone that took it, and no person has checked it. Treat it as a lead until something else in the case agrees with it.

## Giving a photo a date

***What it does.*** On the Evidence screen, Add to Timeline on one or more photos shows a preview of each entry with the date it will take. Date, Time and Place (optional) apply to all the photos chosen; leave all three blank to use each photo's own data. Review Timeline entries shows the preview, then Add to Timeline adds them.

***When to use it.*** Use it when the photo's own date is wrong or missing, for example a camera with its clock unset, or a photo with no date taken.

***How to read the result.*** A photo given a date by a person is named "Photo" instead of "Photo taken". Its source line starts "Date chosen by a person." and keeps the photo's own value beside it, for example "Date taken in the photo's data: 2024-05-03 21:14", or "The photo's data holds no date taken." The receipt counts the photos added, those already on the Timeline (no duplicates are added) and those left out for want of a date.

## Adding payments and findings

***What it does.*** Add to Timeline on the Financial screen, on a money trail or on a finding or observation puts dated events on the Timeline with links back to their sources. A payment takes its transaction date, or its posted, value or effective date when that is all it has. A finding or observation asks for the date the described event happened; this does not change when the finding was written.

***When to use it.*** Use it to bring the payments that matter beside the messages and movements around them. Up to 5,000 payments can be added at a time.

***How to read the result.*** The preview counts what is ready, what is already on the Timeline and what has no payment date. A statement period alone cannot place a payment, so a payment with no date of its own is left in Transactions until its date is edited. An item already added keeps its existing date.

## Attaching files to an event

***What it does.*** On the Evidence screen, Add to event attaches the chosen files to an event already on the Timeline. Find the event by name, date or type, choose it, and press Attach to this event. The event itself stays as it is.

***When to use it.*** Use it to keep photos or documents of a moment with that moment, such as photos of a meeting.

***How to read the result.*** Attached files show as small pictures under the event; point at one to see its name and who attached it. The receipt counts the files attached and any that were already attached.

## The window around a moment

***What it does.*** On a case with phones, Open the window around this opens what every phone recorded around one moment: the chosen event, or the latest timed event, or the latest moment on the phones when the Timeline has no timed events. A payment, which has a date and no time, opens its whole day. Key dates saved for the case appear beside the button as quick choices.

***When to use it.*** Use it to see who was messaging, calling or moving just before and after an event, and to check whether the case's own events sit with that activity.

***How to read the result.*** Each phone has its own row, with the case's events and the money in the window in rows of their own. Hours when a phone recorded nothing read "No data", which is not the same as no activity. Choose an entry to open its phone record. Save this moment as a key date keeps the moment for the case.

## What the phones did in a period

***What it does.*** Once From and To dates are set, What the phones did counts each phone's messages, calls and emails in that period and links each count to the same messages in Conversations. Entries with no time are counted apart and placed in no period.

***When to use it.*** Use it to see which phones were busy across a period under examination, and to go straight to those messages.

***How to read the result.*** One sentence sums up the period. Choose a mark in a phone's row to list exactly that hour, day or week of that phone below. Hours a phone recorded nothing read "No data".

## The phone lens

***What it does.*** Phones, beside the toolbar, opens the phone entries under the Timeline's events: messages, calls, emails, photos and media, and locations at first, each with its phone, names and numbers. Kinds of entry adds or removes kinds such as web and searches, apps, accounts, device activity and sensor readings. Stream lists every entry in time order under day headings. Lanes compares phones, people, activity classes or kinds of record side by side, chosen in Lanes by.

***When to use it.*** Use it to read the phones alongside the documents and payments. On a case whose only dated material is phones, the lens is on the first time the Timeline opens; on other cases it starts off. The choice is kept for the case in this browser.

***How to read the result.*** The heading counts every phone entry under the current filters, and the list holds all of them. A line says how many device events and sensor readings are hidden, with Show to add them. In Lanes, Day, Week, Month and All set the span, with Earlier and Later to move it; choose a mark to list its entries below. "No data" means the phone recorded nothing then. A phone money row counts readings of money taken from the phone, never adds up amounts, and says how many have no time or were rejected by a person. Export saves exactly the entries the lens lists. Opening Show on Timeline from a phone record opens the lens on that record.

## Phone layers on the Timeline

***What it does.*** Above the phone entries, a list of the case's phones with a switch for each, Only this for one phone, and All. Above six phones, a box finds a phone or owner. Each phone shows its number of entries under the other filters.

***When to use it.*** Use it to read one phone, or a chosen few, without the others.

***How to read the result.*** The entries of a phone that is off are not shown and not counted. The line below says, for example, "3 of 5 phones are on. The 2 off are not drawn or counted." The choice carries to the other phone screens.

## Where phones were together

This part appears only where it has been turned on for you, and only with phone layers.

***What it does.*** With two to eight phones on, the lens shows each time the chosen phones were in the same place, with the phones, the time and the records behind it.

***When to use it.*** Use it to test whether two people could have met in the period shown.

***How to read the result.*** "Shared moments" counts the times found. "Busy place: weak" means the place is busy enough that being there together says little. With fewer than two phones on, the screen asks for at least two. What was searched lists what was checked when nothing is found.

## Corroborate a time range

This button appears only where it has been turned on for you.

***What it does.*** Corroborate followed by a number, in the toolbar, puts the events chosen with Ctrl-click, or else every event in the current filters, into one selection, and opens the questions Corroborate can ask about it. The question opens limited to the Timeline's date range, which you can change.

***When to use it.*** Use it to test whether the events in a period share a pattern, such as the same people present each time.

***How to read the result.*** The number is the whole set, not only the events on screen. If not every event can be read, nothing is selected and the screen says so. The Corroborate guide explains the questions and the result.

## Corroborate one event

This menu and key appear only where they have been turned on for you.

***What it does.*** Right-click an event and choose Corroborate this (C), or point at an event and press C. The event joins the selection and the questions open. Shift with right-click keeps the browser's own menu.

***When to use it.*** Use it to start from a single event and add items from other screens to the same selection.

***How to read the result.*** The event shows in the selection tray with the rest of the selection. The Corroborate guide explains the result.

## Adding events to a theory

***What it does.*** Add this range to theory adds every event in the current filters to a theory, with the dates, search words, types and names that chose them. With events picked by Ctrl-click, the button reads Add 3 to theory and adds only those. A Corroborate button beside it starts a look at how the same events could be linked.

***When to use it.*** Use it to keep a sequence with the theory it supports or weakens, so the reason for choosing those events stays with them.

***How to read the result.*** The theory records the events and the filters that chose them. The Corroborate guide explains Corroborate.

## Exporting the Timeline

***What it does.*** Export saves the events as a PDF or CSV file. Choose the events (Current filters, or Selected events picked by Ctrl-click), the format, the level of detail (Compact, Standard or Detailed) and the fields to include. Sources can go in an appendix.

***When to use it.*** Use it to hand a chronology to a colleague or to put it in a report.

***How to read the result.*** The file holds the events chosen, with the fields ticked, under the title you give it. A PDF takes up to 5,000 events; use CSV for more.
