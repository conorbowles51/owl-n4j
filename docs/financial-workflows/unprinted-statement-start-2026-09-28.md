# Statements that print a closing date without a start date

The review must not require an investigator to invent a date. Beside the date fields, a reviewer can explicitly confirm that no start date is printed. The printed closing date is still required. Saving progress and reopening retain that confirmation; entering a start date clears it. A recognised printed start cannot be erased through this option.

Admission retains all payment, balance and reconciliation checks. The saved period records an absent start and a printed end separately. Account history retains the known closing date and reconciled payments, while incomplete bounds cannot establish complete monthly coverage.

Unknown dates do not establish duplicate identity. Before admission, identical source bytes and the exact source section are compared with admitted receipts under the existing case lock. Matching reviewed values add no second set of payments. Conflicting edits remain available and direct the reviewer to existing saved records. Different source pages are not treated as the same statement. This does not claim that different-byte documents with incomplete dates can be automatically identified as copies.
